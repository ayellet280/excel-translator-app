# Excel Translator 📄🔁🇮🇱

אפליקציית Streamlit המאפשרת תרגום קבצי Excel מאנגלית לעברית בעזרת:
- מילון מונחים פנימי (glossary)
- תרגום אוטומטי של מילים שלא נמצאות במילון (באמצעות OpenAI)
- סימון מילים שתורגמו אוטומטית בגופן מודגש ובצבע תכלת

## שימוש
1. העלה קובץ Excel בפורמט חופשי.
2. המערכת תתרגם את כל התאים.
3. ניתן להוריד את הקובץ המתורגם בלחיצת כפתור.

## דרישות
- קובץ `glossary.xlsx` בתיקיית הבסיס עם עמודות: English | עברית
- מפתח API תקין של OpenAI
